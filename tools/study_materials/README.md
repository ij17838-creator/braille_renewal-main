# 단원 학습자료 만들기

게임 전에 받는 단원 학습자료(한글 파일 .hwpx, PDF)를 같은 내용으로 만든다.
만든 파일은 `web/materials/<언어>/<단원 id>.{hwpx,pdf}`에 두고, `data/curriculum/curriculum.json`의 단원에 `materials`를 적으면 로비 버튼이 켜진다.

## 모든 단원이 따르는 틀

| 부분 | 쪽 | 들어가는 것 |
|---|---|---|
| 1. 들어가기 | 첫 쪽 | 사용 안내, 이번 단원에서 배울 것, 규정 알아보기(원문·출처), 핵심 정리 |
| 2. 점형 익히기 | 새 쪽부터 | 점형 카드(필요하면 묶음별로), 헷갈리기 쉬운 점형 |
| 3. 연습하기 | 새 쪽부터 | 읽기 연습, 쓰기 연습 |
| 4. 마무리 | 새 쪽부터 | 게임 전에 스스로 확인하기, 다음 단원 예고, 정답 |

점형이 많아지면 2·3부분의 쪽만 늘어난다. 부분 제목은 '개요 1', 절 제목은 '개요 2'(PDF는 H2·H3)라서 화면낭독기로 제목 사이를 옮겨 다닐 수 있다.

## 화면낭독기 기준
- 점칸 그림마다 점 번호를 글로 함께 적고, 점자 문자(⠼⠁ 등)도 넣는다. PDF의 그림은 낭독기가 건너뛴다.
- PDF는 태그·책갈피·언어(한국어)·쪽 번호를 넣는다.
- 한글 파일 표는 머리행을 표시하고, 칸 안은 설명 → 점자 문자 → ●○ 그림 순서로 둔다.

## 새 단원 더하기
1. `units/<단원>.py`에 `build()`를 만든다. 점형은 저장소 데이터에서 읽고, 규정집 보기와 같은지 `assert`로 확인한다.
2. `build.py`의 `UNITS`에 등록한다.
3. 만든다.

```bash
python tools/study_materials/build.py ko-number --skill <hwpx 스킬 폴더> --out web/materials/ko
```

필요한 것: hwpx 스킬(report 템플릿과 build·validate 스크립트), Node Playwright(Chromium), 인터넷(구글 글꼴 Noto Sans KR).
